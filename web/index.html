🌳 UNDERSTANDING THE HUFFMAN TREE
Analyzing Input...
📌 A. What is this Tree?

A Huffman Tree is an optimal, full binary tree used to generate variable-length prefix-free binary codes for symbols based on their statistical probabilities.

• Leaf Nodes (Orange Circles): Represent individual symbols / byte values from your input, weighted by their exact occurrence frequency.
• Internal Nodes (Purple Circles): Synthetic parent nodes created by merging two subtrees, with weights representing their combined frequencies.
• Root Node (Summit): The single topmost node whose weight equals the total byte count of the input data.
• Binary Edges: Traversing along a left branch designates binary bit 0, while a right branch designates binary bit 1.

⚙️ B. How is the Tree Constructed?

Huffman coding uses a classic Greedy Algorithm with a Priority Queue (Min-Heap):

  1. Frequency Analysis: Scan the entire input and count the occurrence frequency of each unique byte.
  2. Leaf Node Creation: Create a standalone leaf node for each distinct symbol with weight = frequency.
  3. Priority Queue Seeding: Insert all leaf nodes into a min-heap ordered ascendingly by weight.
  4. Extract Minimums: Extract the two nodes with the smallest weights (Min #1 and Min #2).
  5. Combine into Parent: Construct a new parent node with weight = Min #1 + Min #2, assigning Min #1 to the left and Min #2 to the right.
  6. Re-insert: Insert the new parent back into the priority queue.
  7. Terminate at Root: Repeat steps 4–6 until exactly one node remains: the tree root.
🏷️ C. How Do We Obtain Huffman Codes?

To find the binary code for any symbol, start at the Root and trace the unique path down to that symbol's Leaf Node.

Illustrative Example: If the path from root to symbol traverses Left → Right → Left, its assigned code is 010. (Actual codes depend on tree topology and tie-breaking).

Prefix-Free Guarantee: Because symbols reside exclusively at leaf nodes, no valid code word can ever be a prefix of another code word. This enables instantaneous, unambiguous decoding without delimiter tokens.

📉 D. How Does This Help Compression?

Standard uncompressed text stores every character in a fixed 8 bits (1 byte). Huffman Coding assigns shorter bit strings (1 to 4 bits) to high-frequency symbols and longer bit strings to rare symbols.

Because the most common symbols dominate the file, the weighted average code length drops well below 8 bits/symbol, significantly shrinking raw payload size.

⚠️ Archive Overhead Notice: A valid archive also requires a 23-byte header and a serialized frequency table to reconstruct the tree during decompression. Files that are already compressed or have high entropy will not compress further.

🔀 UNDERSTANDING THE GREEDY MERGING PROCESS
Min-Heap Operations
⚖️ The Priority Queue & Greedy Choice

The core of Huffman's algorithm is the Greedy Priority Queue (Min-Heap). At every iteration, it extracts the two nodes with the smallest weights in $O(\log k)$ time.

• Leaf Nodes: Represent initial distinct input symbols.
• Internal Nodes: Represent previously combined subtrees.
• Greedy Choice Property: Combining the two smallest weights first ensures that rare symbols accumulate more edges (longer codes), while frequent symbols remain closer to the root (shorter codes), minimizing the total weighted path length $\sum (f_i \times d_i)$.
• Deterministic Tie-Breaking: When two nodes share identical weights, ByteShrink breaks ties deterministically using their insertion ID, guaranteeing reproducible archives across compressor and decompressor.

🔄 What Happens at Every Merge Step
  1. Inspect Queue: Inspect the current priority queue sorted ascendingly by node weight.
  2. Pop Two Minimums: Extract Node #1 (smallest weight) and Node #2 (second smallest weight).
  3. Sum Weights: Calculate the parent weight: Weight = Min #1 + Min #2.
  4. Assemble Subtree: Set Min #1 as left child (bit 0) and Min #2 as right child (bit 1).
  5. Re-insert Parent: Push the new parent node back into the priority queue.
  6. Check Remaining: If more than 1 node remains, repeat. If exactly 1 node remains, it is the root of the finished Huffman tree!

📖 DSA THEORY & COLLEGE EVALUATION REFERENCE GUIDE

1. Core Data Structures & Algorithms in ByteShrink

  • Greedy Algorithm: At each step, selects the two nodes with the smallest frequencies and combines them. This optimal substructure guarantees minimal weighted external path length.
  • Min-Heap / Priority Queue: Stores candidate nodes in a 0-indexed binary heap array with siftUp and siftDown operations running in O(log k) time. Overall tree construction runs in O(k log k).
  • Binary Tree: Represents prefix-free codes where leaf nodes contain byte symbols and branch edges represent binary bits (0 for left, 1 for right).
  • Bit Packing: Packs variable-length bitstrings MSB-first into raw binary bytes with 64KB buffering.
  • Integrity Checksum: IEEE 802.3 CRC-32 polynomial (0xEDB88320) ensures byte-for-byte exactness upon decompression.

2. Time and Space Complexity

PHASE TIME COMPLEXITY SPACE COMPLEXITY EXPLANATION
Frequency Counting O(n) O(1) Single streaming pass over n bytes with fixed 256-element counter.
Min-Heap Construction O(k log k) O(k) Inserting k distinct symbols into priority queue (k ≤ 256).
Greedy Tree Merging O(k log k) O(k) Exactly k - 1 merges combining two minimum nodes.
Code Generation O(k) O(k) Single recursive DFS traversal visiting 2k - 1 nodes.
Bitstream Encoding O(n) O(1) O(1) array code lookup with 64KB I/O buffer.
Bitstream Decoding O(b) O(1) Traversing tree edges for each of the b payload bits.

3. Shannon Entropy & Pre-Compressed Files

Formats such as JPEG, PNG, MP4, MP3, and DOCX (which is a ZIP container) already employ internal entropy coding (such as DEFLATE, DCT quantization, or Huffman coding). Their byte distribution exhibits near-maximum Shannon entropy (~8 bits per byte). Losslessly compressing an already-compressed file cannot reduce it further, and adding the 23-byte archive header and frequency table results in a slightly larger file. ByteShrink explicitly identifies and reports this honest physical reality.
